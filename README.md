# MergePDF

MergePDF is een open source Python programma voor het samenvoegen van twee of meerdere PDF bestanden. Het maximale aantal PDF bestanden wat tegelijk kan worden samengevoegd is 20.

Bestanden kunnen worden toegevoegd met de knop Bestanden toevoegen… vervolgens kan met de pijltjes knoppen de volgorde van samenvoegen worden aangepast. De bestanden zullen worden samengevoegd in de volgorde zoals deze te zien is in de applicatie. Met de prullenbak knop kunnen bestanden uit de lijst verwijderd worden.

Wanneer het selectievak Open het bestand na het samenvoegen wordt aangevinkt zal het samengevoegde bestand worden geopend na het samenvoegen.

Wanneer het selectievak Verwijder oude bestanden wordt aangevinkt zullen de oorspronkelijke bestanden verwijderd worden. Let op, Het verwijderen van bestanden kan niet ongedaan gemaakt worden!

Door op de knop Samenvoegen te klikken wordt het programma uitgevoerd en de opgegeven bestanden zullen worden samengevoegd tot één PDF bestand.

Er kunnen maximaal 20 PDF bestanden per keer samengevoegd worden.
